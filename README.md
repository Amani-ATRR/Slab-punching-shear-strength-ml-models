Slab Punching Shear Strength – Machine Learning Models

This repository provides the dataset and Orange Data Mining workflow used to evaluate machine learning models for predicting the punching shear strength of reinforced concrete slabs.

Files

Exp_and_FE_data.xlsx – Experimental and finite element (FE) dataset used for model development and evaluation.

ML workflow.ows – Orange Data Mining workflow containing the machine learning models and evaluation procedures.

How to Use

Download both files from this repository.

Install Orange Data Mining.

Open Orange and load ML workflow.ows.

Open the data-input widgets and select the downloaded Exp_and_FE_data.xlsx file.

Run the workflow to examine model performance, predictions, and evaluation results.

Note: Keep the Excel dataset unchanged to reproduce the original analysis. The workflow may require updating the dataset file path after downloading.
