Supplemental Materials

Associated Manuscript: Finite Element- and Machine Learning-Based Prediction of Punching Shear Capacity in Flat Slabs with Embedded Pipes

Authors: Amani Mohammed Smadi and Yasmeen Taleb Obeidat

Journal: Journal of Structural Design and Construction Practice (ASCE)

Manuscript ID: SCENG-2612R1

Description

This folder contains supplementary figures and tables supporting the finite element analysis, machine-learning modeling, and modified ACI punching shear prediction model presented in the associated manuscript.

Contents

Figure S1: Orange Data Mining workflow for correlation analysis, data splitting, model evaluation, and selection.

Figure S2: Comparison of measured/FE punching shear capacities with predictions from ACI 318-25, BS 8110-1:1997, EN 1992-1-1:2023, and the Gradient Boosting model.

Table S1: Hyperparameters of the nine machine-learning models.

Table S2: Detailed validation results for the modified ACI punching shear prediction model.
